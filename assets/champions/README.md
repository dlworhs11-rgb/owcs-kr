# 우승 사진

여기에 사진을 넣으면 대진표 맨 위 우승 카드에 크게 나와요(홈, 결과 페이지).

- 파일 이름: `<연도>-s<스테이지>.jpg`. 예: `2026-s2.jpg` (2026 스테이지 2)
- `.webp`, `.png`도 돼요.
- 가로 사진(16:9)이 제일 잘 맞아요. 폭 1600px 정도면 충분해요.
- 사진이 없으면 로고와 팀 이름이 들어간 큰 우승 띠만 나와요.

올리는 방법(둘 중 하나):
1. PC: 이 폴더에 파일을 넣고 커밋, 푸시
2. 휴대폰·웹: github.com/dlworhs11-rgb/owcs-kr 의 `assets/champions` 폴더에서 Add file → Upload files

몇 분 뒤 사이트가 다시 배포되면 바로 보여요.
